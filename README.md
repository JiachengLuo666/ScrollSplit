# ScrollSplit 2.1：鼠标与触控板滚动分离

适用于 macOS 13 及以上，支持 Apple 芯片和 Intel。原生 SwiftUI 设置窗口与实时菜单栏状态，应用运行无第三方依赖、无需联网。

[下载最新安装包](https://github.com/JiachengLuo666/ScrollSplit/releases/latest) · [2.1.0 更新说明](https://github.com/JiachengLuo666/ScrollSplit/releases/tag/v2.1.0) · [版本历史](CHANGELOG.md)

## 2.1 更新

- 修复从“应用程序”打开时，被仍在工作目录/临时目录运行的旧副本拦截的问题。手动打开同版或新版时，会请求旧进程正常退出；确认退出后，新版才启动滚动监听。旧进程不能退出时会明确提示，不会叠加两个监听器。
- 手动启动始终打开控制面板；首次安装和升级后首次启动也显示窗口。
- 修复窗口最小化、隐藏或留在断开的显示器上时，再次打开看不到界面的问题；窗口恢复到当前鼠标所在屏幕并适配可用尺寸。
- 新增“登录启动时显示窗口”选项。默认后续登录静默启动，手动启动不受此开关影响。
- 新增版本和安装位置提示、“在访达中显示”入口。
- 安装包增加“打开已安装版本”快捷入口；复制完成后双击即可打开 `/Applications/ScrollSplit.app`。
- 保持顶部标题栏拖动、滚动方向、速度与触控板保护逻辑。

## 应用功能

- 独立应用窗口：滚动控制、偏好设置、使用指南三个页面，浅紫配色和设备插画。
- 仅顶部原生标题栏可拖动窗口，内容区用于正常点击与滚动。
- 菜单栏直接显示“运行中 / 已暂停 / 待授权 / 待恢复 / 检查设置”，无需点开菜单判断状态。
- 暂停/恢复、鼠标横向反转、登录启动、权限入口、系统自然滚动提示、服务重连。
- 关闭窗口后保留菜单栏运行，再次从“应用程序”或菜单栏打开会恢复同一个窗口。
- 使用指南提供真实可滚动的试用区域。
- 配套应用图标与拖拽安装 DMG。

## 安装与使用

1. 从菜单栏退出旧版 ScrollSplit，打开 `ScrollSplit-2.1.dmg`，把应用图标拖到右侧 `Applications` 文件夹，出现提示时选择“替换”。
2. 等待复制完成，双击安装包里的“打开已安装版本”，或从“应用程序”双击 ScrollSplit，即可打开完整设置界面。之后可推出 DMG。拖拽复制本身不会自动运行应用。
3. 保持 macOS 系统设置中的“自然滚动”开启。
4. 在界面点击“去授权”，进入“系统设置 → 隐私与安全性 → 辅助功能”，允许 ScrollSplit；如列表没有应用，点击 `+` 添加。
5. 授权后通常约 2 秒内更新状态。若仍未就绪，在偏好设置里点击“重新连接”，或退出后再打开。
6. 在使用指南里的试用区域测试：普通鼠标滚轮向下，视口向页面下方浏览；触控板保持原有自然滚动。
7. 偏好设置可启用“登录时自动启动”。如系统要求批准登录项，在“通用 → 登录项”允许。

直接打开 DMG 中的 `ScrollSplit.app` 也能试用界面。长期使用请先安装到“应用程序”再授权，避免移动路径后重新授权。升级自 1.0 或 2.0 会继承独立滚动和横向反转设置；如果辅助功能条目已开启但仍无效，请移除旧条目后添加“应用程序”里的新版。

保持应用名 `ScrollSplit.app` 与标识符 `local.scrollsplit.app`，本次版本号为 `2.1.0`、构建号 `210`。本版支持手动覆盖更新，尚未接入联网自动更新服务。登录项由 macOS 管理，覆盖后如显示待批准，请在系统登录项中确认。

这是本机编译并临时签名的应用，未使用付费开发者证书签名或 Apple 公证。拷贝到其他 Mac 后如被 Gatekeeper 拦截，请通过系统设置“隐私与安全性”的“仍要打开”批准。

## 流畅度与兼容范围

- 仅监听滚轮事件，直接反转纵向及可选横向的整数、定点和像素增量。
- 不重发事件，不插入动画，不改幅度、时间戳、修饰键、鼠标指针速度或系统自然滚动设置。
- 连续滚动、滚动阶段及惯性事件原样通过，因此常规触控板滚动、惯性和多指手势保留。
- 使用系统公开事件接口和主运行循环；事件回调只做少量字段读写，暂停和权限撤回时停止监听，系统超时或唤醒后恢复监听。窗口与菜单栏共用一个状态模型。
- 设备区分基于 macOS 的离散/连续滚动标志，并非硬件设备 ID。适合普通离散滚轮鼠标；Magic Mouse、部分高精度连续滚动鼠标、把滚轮模拟成触控板的驱动、远程桌面或虚拟输入可能无法正确分离。
- 如另一工具把触控板事件改为无阶段的离散滚动，也可能被反转。请先暂停 Mos、Scroll Reverser、LinearMouse 等工具中的滚动接管功能，避免叠加。
- 未设置鼠标平滑或加速算法。实际设备的延迟、第三方驱动和各软件中的表现需要上机试用，自动测试不能证明体感流畅度。

## 退出与卸载

菜单栏选择“退出 ScrollSplit”，系统原有滚动立刻恢复。卸载前关闭“登录时启动”，再退出应用、移到废纸篓，并在辅助功能列表移除它。工具没有后台守护进程。

## 从源码编译

安装 Apple Command Line Tools 后，在仓库目录的终端运行：

```bash
bash ./test.command
bash ./test-ui.command
bash ./build.command
bash ./test-launch.command
bash ./package.command
```

构建生成上一级目录中的通用 `ScrollSplit.app`。构建前退出运行中的应用。重新编译会改变临时签名，macOS 可能要求在辅助功能列表移除后重新添加授权。

`build.command` 可传入目标 `.app` 的完整路径；`test-launch.command` 和 `package.command` 可传入待测试/打包 `.app` 路径。编译产物不纳入源码仓库，发行安装包通过 GitHub Releases 提供。

DMG 打包脚本需要 Python 3 和网络，会在临时虚拟环境中安装 `dmgbuild==1.6.5`；临时环境在结束后清理。最终应用无 Python 依赖。

`Sources/ScrollFilter.swift` 保留 1.0 的事件方向修改逻辑；`ScrollEngine.swift` 负责监听；`AppModel.swift` 统一设置、权限和状态；`MainView.swift` 是三个 SwiftUI 页面；`App.swift` 管理窗口、菜单栏和应用生命周期。

逻辑检查覆盖鼠标增量、触控板/惯性不变、修饰键与时间戳、横向开关、溢出边界、状态与启动判断、多屏位置恢复。UI 检查覆盖首次打开、菜单暂停/恢复、关闭后常驻、最小化/隐藏/屏幕外的再次打开，以及偏好迁移。真实应用包测试使用隔离标识符，启动后台旧版测试程序后打开新版，检查旧进程退出、新版窗口出现和单实例运行。

UI 检查使用独立预览模型，启动集成测试使用隔离的应用标识，不接管用户当前运行的 ScrollSplit，也不授予辅助功能权限。物理设备手感、重新登录后的系统登录项行为和第三方驱动兼容性仍需真实环境验证。
